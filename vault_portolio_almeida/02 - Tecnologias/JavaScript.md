# 🌐 Linguagem JavaScript

## 📌 Visão Geral
**JavaScript (JS)** é a linguagem padrão da web para interatividade, manipulação do Document Object Model (DOM) e consumo assíncrono de serviços web. Evoluindo com o padrão ECMAScript (ES6+), a linguagem oferece suporte nativo a programação assíncrona baseada em Promises e sintaxe elegante com `async/await`.

---

## 🚀 Uso no Portfólio
- **Consumo de APIs REST:** Utilização da Fetch API com `async/await` para requisições HTTP e parsing de respostas JSON sem recarregar a tela.
- **Manipulação Dinâmica do DOM:** Captura de valores de formulário, injeção de texto com `.innerText` e controle de visibilidade de componentes.
- **Integração com Bibliotecas:** Inicialização e parametrização de animações com ScrollReveal e gráficos com Chart.js.
- **Eventos de Janela:** Monitoramento de rolagem vertical (`window.scrollY`) e rolagem programática ao topo com `window.scrollTo()`.
