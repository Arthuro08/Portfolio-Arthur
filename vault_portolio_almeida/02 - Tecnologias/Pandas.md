# 🐼 Biblioteca Pandas

## 📌 Visão Geral
O **Pandas** é a biblioteca de código aberto padrão da indústria para manipulação, higienização e análise estruturada de dados em [[Python]]. Ela introduz estruturas de dados bidimensionais altamente eficientes (DataFrames) e vetores unidimensionais rotulados (Series), operando com grande performance em memória.

---

## 🚀 Métodos Fundamentais Utilizados
- `pd.read_excel()`: Ingestão de arquivos de planilhas eletrônicas estruturadas com engine `openpyxl`.
- `df.head()`: Amostragem das 5 primeiras linhas para inspeção visual do layout tabular.
- `df.info()`: Diagnóstico do schema de dados, identificação de tipos de colunas e contagem de campos nulos.
- `df.describe()`: Geração instantânea de sumário estatístico descritivo (média, desvio padrão, mínimo, quartis e máximo).
