# 🐍 Linguagem Python

## 📌 Visão Geral
**Python** é uma linguagem de programação de alto nível, interpretada, dinamicamente tipada e com foco em legibilidade e produtividade. É amplamente adotada em desenvolvimento back-end, engenharia de dados, inteligência artificial, automação e desenvolvimento de jogos leves e ferramentas CLI.

---

## 🚀 Aplicação no Portfólio
- **Integração com Bancos Relacionais:** Uso de drivers ODBC (`pyodbc`) para comunicação transacional segura com [[Microsoft SQL Server]].
- **Aplicações Web:** Microframework [[Flask]] para criação de servidores de aplicação e rotas de recebimento de formulários.
- **Ciência de Dados:** Uso de [[Pandas]] para análise exploratória de dados tabulares.
- **Automações e Jogos de Terminal:** Interatividade em tempo real, manipulação de arquivos de log (`datetime`), persistência em formato JSON (`json`) e controle de estado de console.
