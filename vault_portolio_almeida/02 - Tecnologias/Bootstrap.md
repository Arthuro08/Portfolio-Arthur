# 🎨 Framework Bootstrap

## 📌 Visão Geral
O **Bootstrap** é um dos frameworks CSS de código aberto mais populares do mundo para criação rápida de interfaces web responsivas e amigáveis para dispositivos móveis (*mobile-first*). Possui um sistema flexível de grid baseado em Flexbox, componentes pré-estilizados e suporte nativo a esquemas de cores.

---

## 🚀 Uso no Portfólio
- **Dark Mode Nativo:** Ativação instantânea do tema escuro global aplicando o atributo HTML5 `data-bs-theme="dark"`.
- **Componentização:** Estilização de botões, caixas de input e espaçamentos utilitários através de classes prontas.
- **Distribuição via CDN:** Carregamento de folhas de estilo e scripts sem necessidade de gerenciadores de pacotes pesados como npm.
