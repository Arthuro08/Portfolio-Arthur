# 🤖 Scikit-Learn (sklearn)

## 📌 Visão Geral
O **Scikit-Learn** é a biblioteca mais utilizada no ecossistema [[Python]] para Aprendizado de Máquina clássico (Machine Learning supervisionado e não-supervisionado). Construída sobre NumPy, SciPy e Matplotlib, oferece ferramentas eficientes e acessíveis para análise preditiva de dados.

---

## 🚀 Recursos Utilizados no Portfólio
- **Particionamento de Amostras:** `train_test_split` para divisão balanceada entre conjuntos de treinamento e teste.
- **Modelos de Regressão:** Algoritmos lineares (`LinearRegression`) e baseados em árvores (`DecisionTreeRegressor` / `export_text`).
- **Engenharia de Recursos:** Integração direta com [[Pandas]] para codificação de variáveis categóricas (*One-Hot Encoding* via `get_dummies`).
