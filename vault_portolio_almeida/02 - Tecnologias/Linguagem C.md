# 💻 Linguagem C

## 📌 Visão Geral
A **Linguagem C** é uma das linguagens de programação mais influentes e fundamentais da computação moderna. Criada nos laboratórios Bell por Dennis Ritchie, ela oferece acesso direto à memória da máquina através de ponteiros, alta velocidade de execução, tipagem estática e proximidade com a arquitetura de hardware, sendo a base conceitual de sistemas operacionais e bancos de dados modernos.

---

## 🚀 Principais Recursos Utilizados no Portfólio
- **Estruturas Heterogêneas (`struct`):** Agrupamento de campos com diferentes tipos de dados em um único registro conceitual.
- **Ponteiros e Passagem por Referência:** Manipulação direta de endereços de memória para alteração de contadores globais em funções auxiliares.
- **Bibliotecas Padrão:** `<stdio.h>` para I/O formatado, `<math.h>` para funções matemáticas e `<stdlib.h>`.
- **Prevenção de Estouro de Buffer:** Uso de especificadores e máscaras de leitura (`scanf(" %49[^\n]", ...)`) para proteger os limites de memória.
