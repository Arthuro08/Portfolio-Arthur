# 🌶️ Microframework Flask

## 📌 Visão Geral
O **Flask** é um microframework web para a linguagem [[Python]], baseado nas especificações WSGI do Werkzeug e no sistema de templates Jinja2. Destaca-se pela simplicidade, leveza e flexibilidade, não impondo uma estrutura rígida de diretórios e permitindo a rápida criação de APIs REST e aplicações web completas.

---

## 🚀 Uso no Portfólio
- **Roteamento de Requisições:** Mapeamento de endpoints `GET /` e `POST /receber`.
- **Renderização de Templates:** Entrega de formulários dinâmicos com `render_template('index.html')`.
- **Processamento de Payloads:** Extração e parsing seguro de dados de formulário via `request.form`.
- **Integração Transacional com SQL:** Conexão direta com [[Microsoft SQL Server]] utilizando o `pyodbc` para gravação de prontuários com chaves geradas em tempo real.
